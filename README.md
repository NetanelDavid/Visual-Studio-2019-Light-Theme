# Visual Studio 2019 Light Theme (Standalone)

This extension provides the **"Visual Studio 2019 Light"** color theme – originally included as part of the [C/C++ extension for VS Code](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools) by Microsoft – as a **standalone theme**.

---

## 🎯 Why this extension?

The original theme is bundled with the full C/C++ extension by Microsoft, which includes many language features that may not be relevant to all users.

This standalone version is for **users who simply want the Visual Studio 2019 Light theme** – without the extra C++ tooling, language support, or background services.

---

## 🖼️ Included Theme

- `Visual Studio 2019 Light`

---

## 📦 How to Install

1. Open the Extensions view in VS Code (`Ctrl+Shift+X` or `Cmd+Shift+X` on Mac).
2. Search for **"Visual Studio 2019 Light Theme (Standalone)"**.
3. Click **Install**.
4. Open the Command Palette (`Ctrl+Shift+P`) → `Preferences: Color Theme` → Select `Visual Studio 2019 Light`.
